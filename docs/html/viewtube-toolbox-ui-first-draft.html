PRIMITIVE / COMPONENT MATRIX
⌃

Split-left control

Icon rail + content + optional action. The icon rail owns its background; the content area stays visually distinct.

Action button

Heavy border, compact radius, clear semantic surface and predictable L0/L1/L2 sizing.

SubToolbox

Nested shell using the same anatomy as Toolbox, scaled down without inventing a second design language.

StandardInput

Neutral input primitive that inherits the system geometry while allowing arbitrary content sizes.

Dropdown control

Input/control surface with explicit trigger and consistent icon treatment.

Inner action

Action embedded within a SubToolbox body without breaking the outer shell.
