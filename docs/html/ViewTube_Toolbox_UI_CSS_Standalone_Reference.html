10. Invariants

  • Toolbox.tsx remains the canonical shell implementation.
  • The compatibility barrel preserves legacy public imports; it is not a second shell.
  • SubToolbox uses the canonical DOM/state contract.
  • Collapsed shells suppress the seam without producing a double bottom line.
  • ChevronDown rotates between open and closed states.
  • Icon rails inherit palette surfaces rather than forced white backgrounds.
  • L0/L1/L2 share component anatomy.
  • Canonical Component Library examples are production primitives/components.
  • Redundant correction CSS is folded into canonical owners.
  • Work is complete only after verification and merge to main.
