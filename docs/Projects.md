# ViewTube Projects

**Status:** REPORTED / CANONICAL TOOL AUTHORITY TARGET  
**Scope:** Projects page and creator execution workflow

## Purpose
Projects are the execution container where approved creator work, content, assets, tasks and publishing work stay together.

## Four tools

| Tool | Primary job |
|---|---|
| Project Builder | create and configure projects |
| Project Board | manage production lifecycle and status |
| Project Calendar | coordinate timing, milestones and publishing |
| Storyboard Studio | organize scenes, beats and visual production direction |

## Workflow
```text
Idea / Decision
   ↓
Project Builder
   ↓
Project Board + Calendar
   ↓
Storyboard Studio
   ↓
Vault / Editor / Publishing
   ↓
Analytics
   ↓
Brain / learning
```

## Connections
Projects connect to AI Brain, Analytics, Vault, Editor, Studio Hub and publishing workflows.

## Project principle
A Project should carry the context needed to execute approved work rather than forcing the creator to reconstruct context between tools.
