# ViewTube Editor

**Status:** REPORTED / CANONICAL TOOL AUTHORITY TARGET  
**Scope:** creator editing and production workflow

## Purpose
Editor composes video from media, scenes, audio, captions, overlays and other production assets on a timeline.

## Inputs
Video/image assets, scenes, clips, audio, voice, captions, transcripts, overlays, transitions, title cards and project direction.

## Workflow
```text
Project
 ↓
Bring in Vault assets
 ↓
Arrange / edit timeline
 ↓
Audio + captions + visuals + transitions
 ↓
Preview / refine
 ↓
Render / hand off
```

## Outputs
Edited timelines, rendered video, captions/subtitles, edited scenes and production-ready media.

## Connections
- Projects — production context
- Vault — source and reusable assets
- Video Director — directed production plans/media
- Script Architect — script and scene structure
- AI Brain — editing assistance
- Publishing Package — publishing preparation

## User-facing principle
The Editor is a real production workspace, not a generic configuration screen. Its actual controls, states and handoffs should be documented against current implementation.

## Current state
The repository identifies ViewTube Editor as a creator-facing/live surface, while detailed runtime behavior requires verification.
